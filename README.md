# Outil Bar 1.13

Outil de contrôle des stocks, des pertes et des tâches du Bar 1.13 (Mercure Marseille Centre Vieux-Port).

- En ligne : https://rebellin236.github.io/outil-bar-113/
- Données : projet Supabase partagé avec TableFlow, tables préfixées `bar_` (voir `sql/`).
- Connexion : identifiants TableFlow (admins) ; compte dédié pour la tablette du bar.

Étape 1 (en ligne) : connexion, import des exports Bizzon (Stock théorique, Analyse des ventes), page « Aujourd'hui ».
